# High Level Design Overview

## What is HLD

1. Phase of Software Design Life Cycle(SDLC)-> Plan => Architecture of software or Application
2. Bridge Between SRS and actual implementation of system
3. **_Goal_** -> Provide blueprint/roadmap how system will function and various component will interact with each other

## Key Aspects

1. Understand client (requirement), Requirement analysis
2. System Architecture
3. Module/Component
4. Data design interface/ API schema
5. Technology/Tech Choices

## Requirement

> Functional Requirement -> From Product Manager

> Non Functional requirement -> From Architecture/tech. Lead

## Key Take Away's

1. Straight Forward Problem (Junior) -> It is for junior
2. Open ended problem statement (Senior) -> It is for Senior
3. Must ask right question as per junior -> senior
4. Topic doesn't decide intent, don't assume thing. Ask clarifying means instagram is not only image
5. Drive interview with interviews intent
6. System design isn't about coding
7. HDL system design isn't about coding
